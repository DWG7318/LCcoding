# Owner Acceptance Index

LCCoding uses two acceptance artifacts:

1. `LOOP-OWNER-ACCEPTANCE.md` for every normal SLK/CLK/GLK Run after D3.
2. `POST-SECURITY-OWNER-ACCEPTANCE.md` once after centralized vulnerability closure.

Do not combine all normal Runs into one late acceptance. Do not repeat full project acceptance after security remediation; review only the remediation delta and critical smoke path.
