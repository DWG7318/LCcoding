# Project Intelligence

Capabilities are prepared once and invoked only when useful.

- Code Graph: relationships and impact.
- Code Search / ripgrep: exact location.
- LSP: symbol semantics.
- Tree-sitter: syntax structure.
- fd / jq: files and structured data.
- Semgrep, secret detection, dependency intelligence: quality and risk.
- Architecture, database, API, configuration, observability intelligence: enterprise system context.

No tool is run merely because it is installed. The active claim and risk determine tool use. Docker is not a default dependency.

`Project Fingerprint.complexity` records product uncertainty, system coupling, real risk, irreversibility, and novelty to govern analysis, material, and evidence depth. `recommended_loop` remains separate and selects execution topology only.
