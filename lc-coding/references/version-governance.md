# Version Governance

- Start at `0.0.1`.
- Small upgrade: commit only.
- Medium upgrade: increment `0.0.x`.
- Large upgrade: use `0.x.1` according to Owner classification.
- `1.0.1` or above requires explicit Owner authority.

Every promoted version records reason, impact, Calabash/Product Baseline reference, accepted Feature/Run receipts, and delivery status.
