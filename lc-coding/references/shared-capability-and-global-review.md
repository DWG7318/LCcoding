# Shared Capability and Global Review

Check existing reusable capabilities before creating new ones. After a coherent journey,
material amendment, new role/module, or milestone, review UI consistency, Workflow states,
roles, data ownership, reuse, Simulation realism, and accepted Slice compatibility.

UI consistency includes all actor surfaces in scope: customer/client UI, staff/operator
consoles, administrator panels, notifications, audit views, and status displays.
