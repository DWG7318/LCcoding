# Friction Reduction

Reduce internal friction: duplicate reasoning, conflicting Agents, repeated planning, duplicate artifacts, unnecessary tests, and context drift.

Reduce external friction: repeated Owner questions, repository scans, tool calls, network calls, model calls, and handoffs.

Never use friction reduction to remove required product layers, independent authority, or real risk coverage.

All mandatory mainline nodes remain. Their analysis, material, and evidence depth is proportional to product uncertainty, system coupling, real risk, irreversibility, and novelty. Sufficient existing evidence is cited and reused; concise work must remain truthful, while high-risk work must deepen coverage. Do not create empty artifacts to imitate completion.
