# Canonical Governance

The project locks exact skill versions, hashes, compatibility, and load order.

A lock remains valid until one of its inputs changes. Agent session changes alone do not require reinterpreting unchanged standards; a new Agent reads the existing Conformance Receipt and performs only the platform/session identity check.

When conflict exists, cite the conflicting sources, apply canonical priority, and escalate only unresolved Owner-level meaning. Never silently choose a preferred interpretation.
