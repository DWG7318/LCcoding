# Agents Rule

LCCoding generates one canonical project rule source and adapts it to the active Agent platform (`AGENTS.md`, `CLAUDE.md`, Cursor rules, or another supported carrier).

It must include:

- Owner and AI authority;
- mainline and UI lock;
- Git/version rules;
- canonical load and interpretation rules;
- required skills and capability manifest;
- per-Run execution-method selection in any phase and one-topology-per-Run rules;
- Verification evidence reuse;
- Owner escalation boundary;
- delivery exclusions.

Platform-specific files must reference the same canonical rule version rather than diverge.
